          Settings

          Logged in as —. To change the login email/password itself, use Firebase Authentication in your Firebase console.

          Invoice / Seller Details (shown on downloadable order invoices — fill this in for your own registered business, whoever is reselling using this site)

          Leave this OFF if you're reselling without a GST registration — invoices will print as a plain Bill of Supply with no tax lines, which is correct for most small resellers. Turn it ON only if you actually have a GSTIN.

          Active Image Host

          Product photos, review photos, and the delivery-partner logo all upload through whichever host is selected below. If it ever fails (like ImgBB's maintenance downtime), the other one — if configured — is tried automatically as a backup, with no manual switch needed.

          ImgBB

          Free key from api.imgbb.com.

          ImageKit

          From your imagekit.io dashboard, under Developer Options. The Private Key is stored separately from everything else in Settings and is never sent to a visitor's browser — only this admin panel can read it back.

          Migrate Existing Images to ImageKit

          Goes through every product photo, delivery-partner logo, category/brand/blog-category/page image, blog post cover image, and review photo — downloads each one from wherever it's currently hosted (ImgBB, etc.) and re-uploads it to ImageKit, then updates that record to point at the new ImageKit URL. Anything already on your ImageKit URL Endpoint is skipped automatically, so this is safe to re-run. Save your ImageKit keys above first.

          Email Accounts (EmailJS)

          Each free EmailJS account allows roughly 200 emails/month and up to 2 templates. Add as many accounts below as you need, and fill in whichever of the 5 purposes each one covers — leave the rest blank on that card. Sends automatically round-robin across every enabled account configured for a given purpose, so volume spreads out instead of one account hitting its cap.

          Adds a markup on top of every product's Sale Price, site-wide — this becomes the actual price shown to shoppers and charged at checkout. It never appears as a separate "platform fee" on invoices; it's simply baked into the product's price.

          Product Ratings

          One-time fix-up: recalculates every product's star rating from all existing reviews. Only needs running once (reviews submitted from now on update the rating automatically) — safe to re-run any time if you ever suspect a rating looks off.
